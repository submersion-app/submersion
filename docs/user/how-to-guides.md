# How-To Guides

These guides are for divers who are new to Submersion. Each one takes a single goal, such as getting sync working or bringing your dives over from another app, and walks it from start to finish, one step and one screen at a time.

The rest of this user guide is a reference that explains every option of each feature. The how-to guides link into it wherever you want more detail, so you can follow a guide without reading the reference first.
