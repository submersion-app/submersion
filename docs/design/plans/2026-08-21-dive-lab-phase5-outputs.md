# Counterfactual Dive Lab Phase 5 (Outputs: PDF Slate, .sublab File, Multi-Scenario PDF) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Share a scenario with an instructor: a PDF slate (one section per scenario, chart image when captured from the lab page), a versioned `.sublab` JSON file that embeds a dive snapshot so a recipient without the dive can open it (import attaches to the existing dive or creates it), and a multi-scenario PDF from the Saved sheet.

**Architecture:** `DiveLabSlatePdfService` in the `PlanSlatePdfService` mould (`PdfFonts`, `pw.MultiPage`, tables; `pw.MemoryImage` for the chart PNG captured via the lab chart's `RepaintBoundary` key). `scenario_file_codec.dart` (`format: submersion-lab`, `version: 1`, `extension: sublab`) with a `DiveSnapshot` entity built from `LabRequestInputs`; `ScenarioFileImporter` attaches or creates the dive through `DiveRepository` / `TankPressureRepository` and saves the scenario. Share entry points: an AppBar share menu on `DiveLabPage` (PDF / scenario file / chart PNG), per-scenario "Share file" and a multi-select "Share selected as PDF" plus "Import scenario file" on `LabSavedScenariosSheet`. Universal-import routing is deferred (that pipeline sniffs dive-file formats and produces dives; there is no extension router and no `.subplan` UTI either), so import lives in the Saved sheet like `.subplan`.

**Tech Stack:** `pdf` + `printing` via `PdfFonts`, `file_export_utils` (`sharePdfBytes`, `saveAndShareFile`, `exportImageAsPng`), `file_picker` (`FilePicker.pickFile`), `dart:ui` image capture, l10n (11 locales).

**Spec:** `docs/superpowers/specs/2026-08-21-counterfactual-dive-lab-design.md` ("PDF slate", "Scenario file `.sublab`", Phase 5 row).

### Task 3: Importer (real DB)

```dart
class ImportedScenario { final String diveId; final String scenarioId; final bool diveCreated; final bool alreadyPresent; }
class ScenarioFileImporter { Future<ImportedScenario> import(SublabFile file); }
```
Rules: dive exists (`DiveRepository().getDiveById(snapshot.diveId)` non-null) -> if a scenario with the same `diveId` and equal (branchSeconds, mode, interventions, name) exists -> `alreadyPresent` (no write); else save the scenario with a fresh id. Dive missing -> `createDive(Dive(id: snapshot.diveId, dateTime, diveMode, gradientFactorLow/High, altitude, waterType, surfacePressure, setpoints, tanks, profile, notes: l10n-free marker text passed in by the caller ("Shared via a Dive Lab scenario file")))`, then `createGasSwitch` per switch, `insertTankPressures`, then save the scenario (fresh id). Always returns the ids.
- [ ] Tests: attach to an existing dive; create the dive when missing (profile/tanks/switches/pressures present afterwards); identical re-import is `alreadyPresent`.
- [ ] Commit `feat(dive-lab): import .sublab scenario files`
