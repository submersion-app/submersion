Calls I made in this walk-through, each open to change
  • The same card replaces today's "Finish setting up this device" card: when something breaks later, it comes back with only the step that needs you.
  • "Keep devices in step automatically" is on by default in the flow. Today nothing turns Auto Sync on.
  • The cloud copy of backups is on by default once an account exists, and the backup schedule is on by default. Today both are off.
  • Encryption is not in the flow, for dives or for backups. It stays on the feature pages, under Advanced.
  • Photos are the optional step: off by default on a first device, on by default when the library already keeps copies.
  • S3 and WebDAV are one entry, "My own server". An account is the server and bucket; dives, backups and photos each get a folder inside it with sensible default names.
  • Skipping is always allowed, and the card keeps count of what is left.
