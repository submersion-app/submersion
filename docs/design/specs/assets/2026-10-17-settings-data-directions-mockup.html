What the first-timer actually has to do today, from the inventory:

Dives on both devices Data → Database Cloud Sync → tap one of five provider tiles → sign in → tap Sync Now → answer "Combine Libraries?" → scroll down and find the Auto Sync switch (nothing turns it on) → repeat the provider tap and sign-in on the laptop. A copy somewhere safe Data → Backup & Restore → Automatic backups on → Frequency → Keep backups → the Cloud backup switch, which only exists once a sync provider was chosen and silently follows that provider. Photos on both devices Data → Photos & Media → the checklist icon nobody finds → Media storage → a different provider chooser in a different order → retype the same S3 details or "Connect" → the page closes itself → reopen it to tap Upload existing library → on the laptop, a "Finish setting up this device" card asks for the same details again.

Five surfaces pick a cloud place in four different ways, the sync feature has six names, and three different rules decide whether photos count as "set up".

A

Plain words, same pages Small

Keep every page. Regroup the Data page around what the diver wants, say status in plain language, put the one next action on the row, and fold the rarely used rows under Advanced. One vocabulary pass across all the pages.

Fixes

  • Rows read as outcomes with a status a non-diver could parse
  • The next step is on the row, not three screens down
  • Eleven rows become six, with the rest under Advanced
  • One name for each thing across all pages

Still true afterwards

  • Sync and photo setup remain separate journeys
  • Second device still retypes S3 or WebDAV details
  • Three "is it set up" rules keep disagreeing
B

One guided setup for this device Medium

A single re-runnable flow at the top of Data: choose a cloud account once, then sync, backup and photos become three switches on the same account. It replaces the Photos guided setup, the Setup assistant's backup step and the first-run wizard's Backups & Sync step with one set of steps. The detail pages stay for the rare case.

C

Sign in once, then every feature picks an account Medium to large

Connected accounts becomes the only place to sign in, with an Add account button. Sync, photo copies, the backup copy and shared libraries each start with the same row: "Using: Google Drive, Change". The duplicated S3 and WebDAV forms exist once. This is the model the media program spec promised and the shared libraries page already has.

Still true afterwards

  • Largest rebuild: the 1,500-line Cloud Sync page plus Media Storage become one surface

These combine. A is a wording and layout pass any of the others would include. B's first step is C's account picker, so B plus C is one coherent build: sign in once, one guided flow, and every page opening with "Using: …". D is what B plus C looks like if the three features also share one page. My lean, marked as my guess: B plus C, built in that order, with A's vocabulary throughout.
