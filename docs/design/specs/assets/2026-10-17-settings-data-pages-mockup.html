The pages underneath: one shape for all of them

Every feature page opens the same way: which account it uses, one status line, the switches that matter, then everything else under Advanced. Advanced is drawn expanded here so you can check that nothing you use today has gone missing. Is there a control you cannot find?

One sheet, used by step 1, by every Change button and by shared libraries. Accounts you already have come first. The warning is today's "Switch sync backend?" text, shown inline when it applies; for photo copies the equivalent is today's detach-then-attach, with the "which store does the cloud hold" check kept.

Rules behind the shape
  • An account is a sign-in: an Apple ID, a Google or Dropbox account, or one server and bucket. Dives, backups and photo copies each get their own folder inside it, with the default names used today (submersion-sync, Submersion Backups, submersion-media).
  • Existing S3 and WebDAV rows that only differ by folder merge into one account when they share a server, bucket and credentials. Rows from different servers stay separate.
  • "Stop" on a feature page turns that feature off on this device and keeps the account. Signing out or removing an account happens only in Connected accounts, with the list of affected features, as today.
  • Status lines are one sentence in plain words: what is true, and when. Red is reserved for data that may not be protected.
  • Everything that moved under Advanced keeps its current page and dialogs behind the row. Nothing is deleted; the pages are re-parented.
  • Database storage, Offline maps, Import options and Data tools are untouched apart from moving under Advanced on the Data page.
