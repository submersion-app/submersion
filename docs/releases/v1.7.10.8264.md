# 🎉 Submersion v1.7.10.8264 Release Notes

v1.7.10 brings 100 merged changes since v1.7.9. The headliners are gear condition intelligence (Submersion now watches your O2 cells, transmitters, scrubber and check-ins and tells you when something is drifting), re-parsing a file-imported dive from the original file it came from, a "Replan this dive" action that opens a logged dive in the planner, dive site types and tags, a Site Details page you can arrange like Dive Details, CSV exports in your own units that re-import cleanly, a tool that turns imported buddy text into real buddy records, MacDive libraries that import each diver into their own profile, UDDF exports that finally carry your recorded profiles, GPS and roles, an always-on error log with one-tap diagnostics, and statistics by water temperature. This release upgrades the database (schema 207 to 218) and raises the sync compatibility floor, so please read the upgrade notes at the end.

---

## ✨ New and improved

### Gear condition intelligence

Submersion now watches the condition of your gear and tells you when something is drifting, without ever predicting a failure date, a remaining life or a probability. Every dive gets a sensor summary (true minimum temperature and maximum depth, scrubber minutes, how each O2 cell behaved against its peers, how often each transmitter dropped out), you can log gear check-ins from a dive's gear rows or the item's page, and an incident can name the item involved. A condition engine turns exposure history, sensor summaries, check-ins and incidents into findings written as plain sentences in your units: a cell whose output is falling or that disagrees with the others, rising transmitter dropouts, a recurring issue, issues that cluster on cold or deep dives, and linked incidents, each with an evidence sheet that opens the dives behind it.

An item's page gains an exposure card, the findings, a trend chart for the quantity that matters for its type, and a children card for the cells and batteries installed in a rebreather, computer, transmitter, light or DPV, with one-tap replace. Equipment tiles badge the worst finding, trips show a scrubber margin card per rebreather, the pre-dive checklist lists significant findings, Statistics > Equipment gains exposure and findings rankings, and a CCR dive's profile chart shades where a cell disagreed with its peers. It is on by default; Settings > Equipment condition holds the master switch, one switch per rule and a "Rebuild sensor summaries" action. Cell findings need profiles with O2 cell data, and transmitter findings need a transmitter linked to a cylinder.

### Re-parse a dive from the file it came from

A dive imported from a file used to be parsed once, after which every parser improvement passed it by and the only fix was to delete and re-import, losing notes, buddies, site and gear. Submersion now keeps the original file inside the database (compressed, synced and backed up) and adds an action to the dive's overflow menu that re-parses it from that file. The re-parse rewrites only the computer-derived data (times, depths, profile, gas switches, tank pressures and events) and leaves everything you authored untouched; if it cannot run, the page says why. Only dives imported from now on have a stored file, and CSV, MacDive and other database imports store none.

### Replan a logged dive in the planner

A new "Replan this dive" action on the dive detail page turns a logged dive into an unsaved plan and opens it in the planner, so you can change gas, depth or time and see how the deco and gas requirements would have differed from the dive you actually did. Only the working part of the dive is authored so the planner computes the ascent itself, the computer's logged gradient factors are applied, tissue loading can be seeded from a previous dive within 24 hours, and the original profile is drawn as a dashed overlay beside a plan-versus-actual strip. The planner also gains tappable deco stops with a minimum duration per depth, working air breaks, per-plan gas options (bottom and deco RMV, problem-solving time, ppO2 overrides, a best-mix END target), and typed number boxes in place of the setup sliders.

### Dive site types and tags

A site can now carry any number of types from 16 translated built-ins (lake, wreck, wall, pool, cave and more) plus custom types you define under Settings > Site Types, shown on the site's Location card, on site cards, in the site list and its filters, and in a new dives-per-site-type chart under Statistics > Conditions. Tags remain one shared list, but each tag now has a scope (dives, sites or both, set under Settings > Tags), so site-status tags such as "to try" or "to avoid" never clutter the dive tag picker. Site tags get their own card on site detail and their own filters, and both types and tags sync, survive site merges, and travel through UDDF export and import.

### Arrange the Site Details page

The Site Details page gets the same display-options menu Dive Details already has: choose a Detailed or List layout, tick and drag each of its seventeen cards to show, hide and reorder them, or open the new Settings > Appearance > Sites > Site Detail Sections page. In the List layout every card folds behind a header. Choices are per diver and sync between devices.

### CSV exports in your units, and a real round trip

The dives, sites and equipment CSV exports now offer a unit choice. "My units", the new default, follows your settings and names the unit or format in every column header (Max Depth (ft), Water Temp (°F), Date (MM/DD/YYYY)); "Metric" produces exactly what earlier versions wrote. Before this change no Submersion CSV re-imported at all. All three are now recognised automatically by the import wizard, in either unit mode, skip Map Fields, and convert each value back from the unit named in its header, so dives return with their first tank and gas mix, weather, custom fields, dive types and site, and equipment with all its attributes and assembly parts.

CSV import from other apps improved too: day-first slash dates and two-digit years are read correctly (one UK logbook that imported 937 of 2,278 dives now imports them all), rows whose date cannot be read are listed by row number, tags are actually attached to their dives, suits become wetsuit or drysuit gear when their name says which, and MySSI imports get linked sites and buddy records.

### Buddy names become buddy records

Dives whose buddies exist only as text (typically CSV imports) can now be converted into linked buddy records. A Link button on the dive's Buddies card opens a review sheet that splits the text into names, matches each against your existing buddies and lets you correct, reassign or drop any of them before linking; Settings > Data Tools > Link buddy names does the same for every imported dive at once, and every run can be undone. Until you convert them, a text-only buddy shows as a plain tile instead of the dive claiming "Solo dive", and the CSV, Excel and PADI exports now print linked buddies and dive masters, which they used to leave blank.

### One MacDive library, several divers

A MacDive library can hold several divers, and until now every dive in it went into the active profile with a tag per diver name. The import wizard gains a Divers step for multi-diver libraries (MacDive.sqlite and XML alike) that sends each MacDive diver's records to an existing profile, a new one created during the import, or nowhere. Sites, buddies, gear and tags follow the dives that use them, duplicate checking runs per profile, and a one-diver library imports exactly as before. MacDive XML gear now arrives with its real type instead of Other.

### UDDF exports that carry everything

The full UDDF export contained no recorded dive profiles or tank pressures (it wrote an invented descent, bottom and ascent outline in their place, and importing the file back stored that outline as the dive's profile), and it dropped every dive's entry and exit GPS, every per-dive role and your own role on each dive. All of these are now written and read back, an older file's invented outline is recognised and dropped on import, and importing into a second profile no longer shares the first profile's roles and people. The dives-only export gains "Include dive participants" and "Include gear" options, both on by default, so sharing selected dives no longer loses the team and the gear. UDDF files exported before this release still lack all of this, so export again if you keep UDDF files as an archive.

### An error log you can send with a bug report

The log file used to be written only after finding the hidden five-tap debug gesture, so bug reports arrived without diagnostics. The app now always keeps a log of warnings and errors, with secrets redacted, and a Diagnostics card under Settings > About offers View log, Copy diagnostics (a build and device header plus the newest log lines, sized to paste into a GitHub issue) and, on desktop, Open log folder.

### Statistics by water temperature

Statistics > Conditions gains a "Dives by Water Temperature" chart with four bands (cold, temperate, warm and tropical) defined in your own temperature unit, and under it a table of each band's dive count, average gas consumption and average bottom time, so you can see how gas use changes between cold and warm water. The Suit Thickness statistic, empty for many logbooks, now also counts drysuit dives and wetsuits without a recorded thickness.

### Smaller additions

- **A re-downloaded dive segment is recognised.** When a computer splits one dive into two entries and you have already merged the first into a combined dive, re-downloading no longer imports the second entry as a new dive: a third duplicate check matches its start time and depth curve against the existing dive and defaults it to skip.
- **USB computers are easier to find** in the connection wizard: the search bar is always visible and a manufacturer dropdown filters the list to one brand.
- **CCR bailout gases are ranked against each other** on dives downloaded without a transmitter or tank record. The usage the computer reports (oxygen, diluent, sidemount) is kept; the remaining gases are ranked by O2, with the lowest becoming Bailout, 41% or more becoming Deco and the rest Stage.
- **Automatic import tags can be turned off.** A "Tag imports automatically" switch on the Tags page (on by default) controls the "{source} Import {date}" tag every import used to add, and the wizard's Import Options sheet can override it for one import.
- **Shift-click** in the import wizard's review lists checks or unchecks every row between two clicks.
- **A Spare equipment status** for gear that is usable but not in the dive rotation. Spare gear keeps its service clocks and statistics but stays out of the pickers that add gear to a dive, a plan or a weight rig.
- **Hoses gain a Hose type field** (LP, HP or LPI), and once a category is picked in the Equipment list filter, chips appear for each of its choice fields. The dive filter sheet gains a matching Gear attributes section, and the main dive list now honours it (a Suit thickness filter used to narrow only the table view).
- **Hose and SMB length show in inches or centimetres** rather than the depth unit, so a 15" hose is entered as 15, not 1.25 ft.
- **Tank Band, Weight Pocket and Gear Pocket** join the BCD family as their own equipment types, each with its own icon and fields.
- **Retype gear stored as Other.** Settings > Data Tools > Retype gear marked Other lists items whose name says what they are (suits from older CSV imports, gear from older MacDive XML imports), each with its proposed type, and applies the ticked ones with Undo.
- **The Equipment list groups by type** with the same type order the dive's gear list uses, and every gear surface opens one shared Sort sheet.
- **Parts show where they belong.** An item's Components card opens with a "Part of" section listing the assemblies it belongs to, and an O2 cell or battery shows "Installed in" its host with the install date and age.
- **The Cylinders card pairs with Gas consumption by segment** on a wide dive detail pane, so tank pressures and the consumption they feed are read together; Weights now pairs with Buoyancy.
- **Tag chips on a dive open the dive list filtered to that tag**, the Edit Tag dialog gains a Delete button, and tag delete and merge messages count sites as well as dives.
- **The "Sync dive computer clocks" switch** is now the first card under Transfers > Dive Computers, where before it was hidden on a list only reachable from the Dive Log.
- **Selecting dives keeps the dive numbers visible.** The checkbox slides in beside the number, site avatar or buddy avatar instead of replacing it, in every list with selection mode.
- **"Retain source dive numbers" works for every import source** that provides a number, is disabled with an explanation when none does, and warns when retained numbers clash with dives already logged.
- **The import summary shows every parser warning** as its own card, data loss first, including a "missing dives" card for dives a parser could not read.
- **Large exports are much faster.** The full UDDF export, the logbook and course PDFs and the maintenance log read their related data in batches instead of one query per dive or item.

## 🐞 Bug fixes

**Imports and exports**

- Re-parsing a dive whose fresh parse happened to return no tank data deleted its cylinders and entire tank-pressure history. Existing tank data is now left alone in that case; data already lost this way can only be recovered from a backup.
- Importing several files at once merged records that shared a name even within one file, so two different "Chris Diver"s in one file became one person. Records with different ids in one file are always kept apart now.
- When the import review flagged a gear item as a duplicate and you chose Skip or Link to existing, its dives imported without it and the default gear set was applied instead. They now link to the existing item, and gear stored as Other matches a typed re-import by name.
- Exports wrote a custom dive type under a name rebuilt from its id ("Search recovery" for "Search & Recovery"), and the desktop dive table did the same while leaving built-in types untranslated. Both now use the type's real name, and the CSV carries type ids so a re-import recreates custom types.
- The Detailed PDF's Team section printed stale free-text dive master names alongside the linked team; the text now prints only when nothing is linked.
- Suunto Cloud imports never captured the exit surface GPS fix, so the Surface GPS card showed no drift. Re-import affected dives to pick it up.
- A leftover temporary file briefly locked by iCloud Drive could make a backup restore fail and leave the app with no open database until it was force-quit. Restore now rolls back and reopens the database.
- Several failure paths in a backup restore could leave the moved-aside copy of your database as the only copy, and the next launch deleted it as a stale leftover. Restore now keeps that copy until it is provably stale, and an interrupted restore is detected on the next launch with a choice to recover the previous database or keep what is there.

**Dive log and charts**

- On macOS, zooming into the fullscreen profile chart past about 5x and panning drew garbage: blanked series, stray triangles, smeared text, and a readout digit that stayed corrupted until relaunch. The hover markers also drifted to another time while panning.
- Selecting a dive in the master-detail list made the header map blink on every selection, and the header card flashed a bright line along its bottom edge on overscroll bounce.
- On a narrow Cylinders card the tank name was squeezed to nothing beside the SAC and RMV rates, and in German the card could fail outright.
- Long dive and site card titles were cut off with an ellipsis on narrow windows while trip and equipment cards wrapped; all four lists now wrap.
- The table view's profile panel kept previewing a highlighted dive after a filter change excluded it.
- With a buddy filter active, the dive list, previous/next navigation and the map views did not refresh when only buddy links changed, and the maps ignored the buddy link check entirely, so an unlinked dive stayed on the map after leaving the list.

**Equipment**

- Deleting a gear item that a cylinder was linked to through the transmitter registry failed with a database error, on the deleting device and again on every peer the delete synced to. It now succeeds and clears the link on the cylinders that used it.
- Setting a service clock's Baseline date had no effect whenever a service record of the same kind already existed. A baseline you set now outranks every record logged before it, and each clock shows "Counting since {date}".
- A BCD's Exposure card showed "N battery cycles" equal to its dive count, and unpowered gear appeared in the Battery cycles ranking. Cycles now accrue only on powered gear, or on any item you give a battery-cycles service clock.
- Mass values on equipment (dry weight, buoyancy, lift capacity) were rounded to one decimal on display and in the edit field, so a 0.35 kg trim weight read 0.3 and saving wrote the rounded value back. Mass fields keep two decimals now.
- "Due soon" chips read lavender under the default theme, and in the Console, Tropical, Minimalist and Deep presets a due chip matched an OK chip. A fixed red, amber and green status palette now applies everywhere gear urgency is shown.

**Statistics and planner**

- The Solo vs Buddy statistic counted a dive once per linked buddy, inflating the buddy share for anyone who logs group dives.
- The planner's RMV slider showed its raw litres-per-minute value labelled with the imperial unit, so 15 L/min read as "15 cuft/min". It now works in cuft/min for imperial divers and L/min for metric ones.
- The deco calculator's gas safety card showed ppO2 in the tank pressure unit, so 1.28 bar read as "19 psi". It now shows bar with two decimals like every other ppO2 readout.

**Sites, tags and buddies**

- On Android, the option that rewrites site place names in your chosen language still stored region names in the local language, because Android's own geocoder translates only the country. Android now uses the same Nominatim lookup as the desktop platforms; run the refresh again to repair existing sites.
- A failed tag save closed the dialog without a word and lost the edit. It now reports the failure, keeps the dialog open with your edits, and blocks a double tap from creating a tag twice.
- Tapping a row under Settings > Manage > Tags briefly opened the dive list; rows are inert again and the edit button is the way in.

**Dive computers, bathymetry and 3D**

- Swiss lake sites often reported "no bathymetry data available" after a long stall and never rendered in 3D. The app parsed an entire per-lake archive for every tile (43 seconds and about 1 GB of memory), the lake list did not match what swisstopo publishes, an ocean-tuned quality floor rejected narrow lakes, tiles where two lakes overlap used the wrong water level (about 14.6 m off between Rotsee and Vierwaldstättersee), and a transient network failure was cached as permanent. All fixed, and tiles cached with the wrong level are discarded and fetched again.
- The 3D terrain view stretched depth and horizontal distance independently, so a gentle lake bed rendered as a near-vertical plunge. Depth now uses the same scale as the horizontal axes.

**Platform**

- On Linux and Windows, opening a dive whose photos were linked from a Mac or phone gallery popped up an "Open File" dialog that reopened when cancelled. Those photos now read "From another device" and no dialog appears.
- On a second Apple device sharing an iCloud Photo Library, "Scan gallery for photos" and the photo pickers offered every already-linked photo as new and created a duplicate link for each. Duplicate links created before this fix are not removed automatically.

## ⚠️ Upgrade notes

- **The database upgrades from schema 207 to 218.** The migration runs once on first launch and the app takes an automatic backup beforehand, so there is nothing you need to do first.
- **Update every device in your sync library.** This release raises the sync compatibility floor, so a device still on v1.7.9 or earlier stops receiving changes from an updated device until it updates too. Its own changes still arrive on the updated device, so nothing is lost, but the older device falls behind until you update it.
- **Dives imported before this release cannot be re-parsed from their original file**, because no file was stored for them. Re-import them once if you want that option in future. Re-parsing from the file overwrites hand corrections to computer-reported values, exactly as the dive computer re-parse does.
- **Every existing tag becomes dive-only.** To use one on sites, widen its scope under Settings > Tags. A new tag takes the scope of the place it is created, and narrowing a scope removes the tag from the affected dives or sites after a confirmation.
- **Service clock baselines set before this release keep the old rule** (any record of the kind wins). To move one onto the new rule, open the clock's Baseline date picker and pick the date again; the same date is fine.
- **Gear stored as Other by earlier CSV or MacDive XML imports is not retyped automatically.** Use Settings > Data Tools > Retype gear marked Other, and review the proposals: a bare "dry" in a name reads as a drysuit, so "Dry bag" should be unticked.
- **The CSV export default changed from Metric to My units.** Choose Metric in the export dialog for the old output. CSV tanks imported before this release were stored as air; re-import to recover their mix.
- **The Equipment list opens grouped by type** and ascending now means A to Z and oldest first, matching the dive surfaces. Choose "Do not order by type" in the Sort sheet for a flat urgency-first Service Due list.
- **Cylinders moves up in the default dive detail card order** to sit beside Gas consumption. A card order you set yourself is kept.
- **Minimum-gas figures for existing plans shift slightly**, because problem-solving time now defaults to 2 minutes at the stressed RMV instead of an implicit 1 minute. Per-depth stop minimums are honoured by Buhlmann only.
- **The log file is now written for every user**, not only in Debug Mode, with secrets redacted. Verbose logging is still turned on through the five-tap gesture, and Open log folder appears on macOS, Windows and Linux only.
- **Android place lookups are throttled to one per second**, so refreshing a large site list takes longer than before.
- **Swiss lake bathymetry tiles cached before this release are re-fetched once**, since older tiles cannot prove their water level is correct.
- **An older app version treats the Spare status as Active**, and if an older build edits and saves a Spare item it writes Active back.
- **No minimum operating system change** on macOS, Windows, iOS, Android or Linux.
