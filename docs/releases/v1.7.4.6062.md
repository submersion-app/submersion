# 🎉 Submersion v1.7.4.6062 Release Notes

v1.7.4 is a small, fast follow-up to v1.7.3: ten merged changes, most of them platform maintenance. The substance is a trim tool in the dive profile editor, a fix for a backup folder that could lock you out of the app at launch, and a move to the current Flutter SDK. The database is unchanged, so this update carries no migration.

---

## ✨ New and improved

### Trim the surface tail off a profile

The profile editor gains a **Trim** mode. Many dive computers keep sampling after you are back on the boat, so the profile ends in a long run of 0 m readings. Those samples are not harmless: they stretch the recorded dive time and pull the mean depth down, which in turn skews the SAC rate derived from it. **Trim End** removes the trailing zero-depth samples and keeps a single one, so the profile ends where the dive actually ended. Like every other tool in the editor, the trim goes on the undo stack, so you can step back before saving.

### Rebuilt on Flutter 3.47

Submersion now builds on Flutter 3.47 and Dart 3.13, up from 3.44. That is maintenance rather than a feature, but it reaches every build you download: it keeps the app on a supported toolchain, and it forced updates to the components behind Excel export, PDF viewing and export, and archive handling. Two consequences are visible to you, and both are covered in the upgrade notes: macOS 11 is no longer supported, and desktop builds now render through Impeller.

## 🐞 Bug fixes

- **A custom backup folder the app could no longer write to stranded it at launch** on the terminal "Database upgrade failed" screen, which offers no route back into Settings to correct the folder. An unusable backup location is now cleared and the default location is used instead, so the app starts and the setting reverts to signal that a re-pick is needed. Android users who had chosen a Google Drive folder were the most affected: the system file picker hands back something that looks like an ordinary path, which Android then refuses to create.

---

## ⚠️ Upgrade notes

- **macOS 11 Big Sur is no longer supported. The minimum is macOS 12 Monterey.** Flutter 3.47 requires it. If you are on Big Sur, stay on v1.7.3, which still runs there. iOS remains at 15.0, and Windows, Linux, and Android are unchanged.
- **No database upgrade.** The schema stays at 150, so nothing is migrated on first launch and devices still on v1.7.3 sync with v1.7.4 normally.
- **Desktop rendering switched to Impeller.** Flutter 3.47 makes Impeller the default renderer on macOS, Windows, and Linux. Everything should look the same, but the 3D dive view and the map heat layer draw through custom shaders that this change affects, so please report anything that renders incorrectly.
- **Excel and PDF exports ride on updated components.** The output formats are unchanged, but if a spreadsheet or PDF export looks different from the one v1.7.3 produced, that is worth a report.
