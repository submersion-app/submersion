# 🎉 Submersion v1.8.3.9095 Release Notes

v1.8.3 brings 178 merged changes since v1.8.2. The headlines are a simpler Settings > Data, Git as a new sync and backup backend, logbook rules, and colour correction for underwater photos and videos. Settings > Data is rebuilt around accounts: one account sheet for every cloud location, a guided "Set up this device" flow that the first-run wizard now uses too, one Photos & videos page and a Backups page with an explicit copy destination. Logbook rules apply "if this query matches, do these actions" to dives and sites after an import or on demand, with preview and undo. Every dive computer and transmitter is now one Equipment item, a download goes to the computer's owner rather than the active profile, and a trip or site can be shared with chosen profiles. The dive list gains a scrubber, Certifications and Courses become one Training entry, Media and Documents one entry, and photos, videos and documents can carry tags. The planner gains global Setup defaults, an editable MOD per cylinder and a deco ceiling warning, and switches gases at their MOD in the plan's water. This release upgrades the database (schema 290 to 318) and raises the sync compatibility floor, so please read the upgrade notes at the end.

---

## ✨ New and improved

### Settings > Data: one account sheet and a guided setup

Settings > Data now says at a glance whether your data is safe: a status strip for Backup, Sync, Libraries and Media, one plain line for anything that needs attention, and a facts line with your dive, site and photo counts and the database size. Under Your data, five rows (Backups, Sync between devices, Photos & videos, Shared site libraries, Connected accounts) each say in one sentence where things stand, such as "Backed up 3h ago, copy in Google Drive", with a Set up action for anything not yet set up. An account is now the one thing you sign in to, and every place that picks a cloud location opens the same account sheet (iCloud, Google Drive, Dropbox, Git or My own server for S3 and WebDAV). Connected accounts shows what each account is used for on this device, warns before Sign out or Remove, and lets you rename an account; well-known storage services read by name, such as "submersion-sync @ Cloudflare R2". A new "Set up this phone" card (or tablet, or computer) walks through four steps: account, sync, backups and photos. Nothing is written until you press Next, and the first-run wizard and Setup assistant now run the same steps. Rarely used items fold under Advanced, including new Import options and Data tools pages, and on a wide window every Data page opens in the detail pane.

### Git as a sync and backup backend

Point Submersion at a repository on any Git host (GitHub, GitLab, Gitea, Forgejo, Bitbucket or self-hosted) with an address, username and access token, and every device syncs through a dedicated branch, `submersion-sync` by default. Git appears in the account sheet and the setup flow with host-specific token help and needs no installed git. Large downloads stream to disk, so big backups restore on low-memory phones, and a missing or damaged index rebuilds itself.

### Logbook rules

New optional rules under Settings > Manage > Rules: "if this query matches, do these actions", for dives and for sites. The condition uses the existing query language with a live "Matches N of your dives" count. Dive rules can set any field bulk edit can, add or remove dive types, tags, equipment, buddies and courses, and append to notes; site rules can set simple fields, tags and types and append to the description. Rules run after an import, after you log a dive or create a site, or on demand from the Rules page or "Apply rules" on a selection, with a preview first. The import summary shows what ran, and a synced history lets you undo any run.

### Colour correction for photos and videos

Underwater photos and videos can be colour corrected on screen without ever changing your files. An optional automatic fix (Settings > Data > Photos & videos > Advanced > Automatic color correction, off by default) warms each photo and video using the depth it was taken at, and leaves surface shots and well-lit photos alone. The Adjust color panel in the photo and site viewers offers Auto, Pick white, Original (press and hold to compare), Strength, Warmth, Tint, Brightness, Contrast and Saturation, plus "Apply to this dive" with Undo. Videos follow the dive's depth as they play. Sharing a corrected photo sends a corrected JPEG that keeps its date, location and camera details, and sharing a corrected video sends a re-encoded copy with a progress dialog and a Share original fallback.

### One Photos & videos page, and backups you can steer

One Photos & videos page replaces the Photos & Media hub and the Media Storage page. You set up cloud copies by choosing an account, which joins the library's existing copies when they already live there, and a status line says plainly what is true ("120 of 340 copied", "Uploads paused"). When the copies' folder no longer matches, a guided Reconnect offers only the choices that fit. The Backups page leads with its status, then Back up automatically, a new explicit "Copy to" destination (including "No copy off this device"), Back up now, Restore and History. A new opt-in "Count backups from all devices" switch makes Keep a ceiling on the whole cloud folder, shows what would be removed before deleting anything, keeps each device's newest backup and honours pins across devices. Storage usage splits device and cloud space, offers Reclaim storage, and cleans up leftovers from restores and re-uploads automatically. The media library caches thumbnails on disk with sizes you can set, so scrolling is smoother.

### Equipment: one entry per dive computer and transmitter

Each dive computer and air-integration transmitter is now one Equipment item carrying every control for the device: a Dive computer section (download, re-import, connections, clock sync, merge) or a Transmitter section (keys, role, cylinder, Apply to existing dives). The Dive Computers and Transmitters lists remain and open these items. A new transmitter serial seen in a download, import or re-parse creates its Transmitter item and adds it to those dives' gear. A tank can now carry several regulators for Y, H or manifolded valves, all counting toward service clocks and usage. A tank's last visual inspection and hydro dates now drive its VIP and hydro clocks. In the transmitter editor, picking a cylinder pre-fills the role from its history and offers to copy the serial onto the linked gear item. First Stage and Second Stage get their own icons.

### Downloads go to the computer's owner, and sharing with chosen profiles

With several diver profiles, a dive computer download now goes to the computer's owner rather than the active profile. The review step says whose log the dives join and offers a picker, and numbering, gear, duplicate checks and rules follow that profile; the switch is under Settings > Data > Import options and is on by default. A trip or dive site can now be shared with Everyone or with chosen profiles from a "Shared with" row, "Share with..." on a selection, or "Share all my trips/sites..." in Settings > Shared data. If a second device created its own empty profile before its first sync, the Dives list now points to the profile holding the dives and offers Switch, Merge or Keep both.

### Dive log: a scrubber, jump to a dive number and lists that remember

The dive list has a scrubber: grab the handle on the list edge to cross a long log in one drag, with markers for the active sort (years and months, depths in your units, dive numbers, site letters, ratings), trip stripes and monthly count bars. Typing just a dive number in search, such as 500 or #500, jumps to that dive. Every record list returns to the record you last opened when you come back, and master lists support Home, End, Page Up and Page Down (Cmd+Up and Cmd+Down on macOS). Fast scrolling stays smooth on a large log, Dive Details fills in sooner on a phone, detail pages place values beside their labels on wide windows, dive notes can be selected and copied, and the Cylinders card is a tidy table of tank, gas, start, end and used.

### Navigation: Training, and Media with Documents

Certifications and Courses are now one Training entry with a "Certifications | Courses" switch, and Media and Documents are one entry with tabs. Each tab keeps its scroll, selection, filters and open form across a switch. Saved navigation orders and shortcuts are migrated, and existing links keep working.

### Planner and gas calculators

Every field in the planner's Setup accordion now follows new global defaults under Settings > Safety > Decompression (Planner rates, Gas, Contingency, DPV Team) unless the plan overrides it, shown as a greyed hint until you do. Each cylinder has an editable MOD in the tank dialog and on saved cylinders, which now use a card layout; a typed MOD sets where the plan switches to that gas. Gas switches now follow the plan's water type, salinity and altitude, so no line reads above the deco limit. An authored ascent that passes the deco ceiling raises a critical "ceiling violated" issue, and repetitive dives carry their tissue loading into contingencies, the range table and bailout. Long-press a chart waypoint on touch (or right-click) to remove it. Saved plans are grouped by mode and sortable, and blank Turn and Min gas figures now say what is missing. CCR plans without their own setpoints use yours from Settings. The ICD calculator offers oxygen-based fixes beside helium ones, and the MOD calculator's density check follows the selected gas temperature.

### Tags on photos, videos and documents

Photos, videos and documents can carry tags from the shared tag list: a Tags field and filter for documents, and a Tags card, library filter and "Edit tags" on a selection for media. Turn on "Use for media" or "Use for documents" for a tag in Manage Tags first. Documents can also be exported all at once as a password-protected ZIP with a manifest, from the Documents menu or Transfer > Export.

### Dive sites and dive centers

A dive site can list several entry and exit methods, and a site's menu has Duplicate, which opens a pre-filled unsaved copy. Site search ignores case for accented letters, shows real dive counts and keeps its results when you go back. New divers get a planning-first order for the Site Details cards. A dive center can be marked Permanently closed, and the dive center picker lists centers near the dive's site first. Shared site library owners can remove members, view and change the library's connection, and edit its name and a new description.

### Tracks and maps

Tracks rows match the dive list, an underwater track gains "Change device" and a 3D scene view that scrubs through depth, temperature, speed and battery voltage, and track speed reads in m/min or ft/min. Every full map has a layers button for Street Map, Topographic and Satellite. Track maps zoom and scroll like the other maps. The offline region picker gains Move and Select modes, zoom buttons and corner handles.

### Imports

The Suunto cloud import brings in buddies and the details logged in the Suunto app (dive center, visibility, current, weight, sightings, suit, notes and more), filling only what the dive does not already have, and Submersion appears in the Share sheet for a JSON dive shared from the Suunto app. MySSI CSV exports from my.divessi.com import, and every CSV import now reads units written after a number, such as "35 ft" or "3,000 psi". divelogs.de imports bring their photos, file and divelogs.de imports keep running in the background if you leave the wizard, show photo download progress and ask before you leave. A new "Skip unused bailout gases" setting under Settings > Data > Import leaves programmed but never-carried gases out of CCR and SCR downloads. Running the Apple Watch import again corrects dive times that v1.8.0 and earlier saved shifted by the UTC offset.

### Imports pick up your recorded GPS tracks

Dives from every import source (dive computer downloads, Suunto, Garmin and files) now take their entry and exit positions from a recorded GPS surface track during the import, so the summary's "Match N dives to sites" offer already sees them. Before, positions only arrived later, from Stop logging, the next sync or Match on the Tracks page. Only dives with no position are filled, and a position the file or watch already carries is kept. When the new position falls inside a geofenced equipment set, a newly downloaded dive takes that set in place of the default one.

### Insights and Connections

Time Patterns groups dives by sunrise and sunset at the site into Dawn, Morning, Afternoon, Dusk and Night. Insights > Gas gains a Tank configuration card (rebreather, sidemount, twin or single backmount, stages and deco gas). Rebreather dives are left out of SAC and RMV statistics. Pie chart percentages are readable on pale slices. Connections opens on Who dives where, and every map carries a caption explaining how to read it.

### Smaller additions

- **Dive filter:** a "No Role Assigned" switch under People finds dives where your own role was never set, and the query language gains `role:none` and `role:any`.
- **Settings > Safety** is now a hub with Safety review, Decompression and Equipment condition, each showing its current state (such as "GF 30/70").
- **Checklists** have real sections in place of a free-text category, with add, rename, reorder and drag between sections.
- **Certifications:** IART is a built-in agency with its own course categories; the list can be grouped by Status, Agency or None, and a View switch moves between the list and the wallet; course pages show each earned certification's card photo.
- **Settings:** "Always hide labels" is separate for phone and desktop; the Manage Data tiles are grouped into seven sections; Display size sits on one row when there is room; long translated labels move their controls onto their own line instead of breaking one letter per line.
- **Data quality:** a "Transmitter role" check spots a CCR bailout imported as the O2 supply and offers "Use as bailout"; clock-offset repair can fix just the wrong computer's clock; CCR loop cylinders are no longer flagged as the wrong tank.
- **Themes:** text and icons are readable in dark mode and in the Console, Deep, Minimalist and Tropical presets, and Buddies uses a calm sage accent instead of alert pink.
- **Marine life:** your edits to built-in species now show everywhere and sync.
- **Documents:** a dive owner reads as "#142 · Blue Hole · 12 Oct 2026", and Delete moved into the detail page's overflow menu.

## 🐞 Bug fixes

**Dive computers**

- A Bluetooth computer downloaded on one device and synced to another stopped there with "Submersion has no saved connection", because Bluetooth addresses stay on each device. The other device now scans for the one nearby computer of the saved make and model, checks its serial, and remembers it; with none or two in range it says so and offers Try Again.
- Halcyon Symbios downloads often failed partway; a stalled block is now re-requested. Cressi Raffaello is now supported.
- On Android, the Apeks DSX and Aqualung i330R asked for a four-digit PIN the computer never showed; Submersion's own PIN dialog now completes the pairing.
- On Android, downloading a saved Shearwater Petrel 3 or Perdix 2 from Known Computers failed while "Connect new computer" worked.
- On Android, Submersion no longer bonds Cressi Bluetooth adapters up front, which appears to have broken Cressi downloads. Remove the adapter from Android's Bluetooth settings before trying again.
- A re-parse that came back empty, as with a Mares Genius, could wipe a dive's depth, duration and profile; the dive is now left untouched.
- For Suunto and Shearwater Cloud dives, CNS and OTU were held only in the computer's tissue data, so the dive's own fields stayed empty.
- Re-importing a dive kept a stale tissue snapshot even when the new reading had none.
- A dive could list two data sources for one recording when two import paths spelled the computer's name differently.
- On a Shearwater CCR dive, applying a cylinder configuration inserted a duplicate bailout when a transmitter's role had been guessed from its name.

**Dive log and analysis**

- On sidemount and some twin dives, the Cylinders card showed a per-tank SAC only for the first cylinder.
- "Analyze all dives" did not regrade dives that already had a safety review, and a re-parse kept the old review.
- Imported steel cylinders with no material were treated as aluminium, reading several kilograms too buoyant; the Buoyancy card now says when it had to guess a material.
- Editing a CCR dive with no recorded setpoints showed your Settings setpoints as if they were the dive's own, and could save them.
- Insights could measure an edited dive by its pre-edit profile.
- The Details card kept showing imported buddy text after you linked real buddies.
- With two profiles sharing a custom tank preset name, one diver's imports could get the other's cylinder size.
- Duplicate per-diver settings created on two devices before a sync could cause "Too many elements" errors.
- A dive card's tap ripple was cut short, and the scrubber jumped the list when released on a dive already in view.

**Planner and calculators**

- The planner switched to EAN40 at 30 m with a ppO2 of 1.61 against a 1.6 limit, because switch depths ignored the plan's water.
- Manually ascending straight to the surface while deco was owed raised no warning.
- On a phone, a chart waypoint could not be removed.
- "+null" showed in the Contingency chips, the deviation table and the PDF slate.
- Typing the first digit of a multi-digit MND made the field disappear and left the mix as air.

**Sync, backup and accounts**

- On iOS, Android and the macOS App Store build, Google Drive sync failed with an invalid token about an hour after sign-in; the token now refreshes silently.
- A shared site library could lose its storage account after a restart, and its sync errors appeared partly in English.
- When one device moved its photo copies to another account, the other device marked them missing everywhere and some photos bounced between stores.
- Certification card photos were stored twice since Documents arrived, nearly doubling backup size.
- The Settings > Data rows could claim things they did not know or stay stuck on "Checking...".

**Imports**

- A Dive Log import moved a single transmitter's pressure onto the stage cylinder after a gas switch.
- DiveMate's XML export lost almost every dive site, and its UDDF export imported the word "null" as notes and serial numbers.
- Restoring a Submersion UDDF file added a phantom gas switch at the start and gave a tankless dive an air cylinder; real switches dropped on restore now come back.
- A very old upgrade step shifted dive times by today's UTC offset rather than each dive's own, and GPS track import proposed today's offset rather than the one in force when the track was recorded.
- Fetched weather used the wrong hour for any site outside GMT. Re-run Fetch weather on affected dives.

**Media, maps and layout**

- Videos never played on Windows; a failed video now says so instead of spinning on every platform.
- On Intel Macs the whole window flickered from launch, in every release since 1.7.9.
- Swiping to the next photo slid in a blank panel first.
- Phones had no way to change the Media library's thumbnail size.
- On Windows, a touchpad pinch zoomed maps and charts the wrong way.
- Site Details stuttered past the seascape card; a plain wheel or two-finger swipe there now scrolls the page.
- Links that open the Trips list lost their way back, and the dashboard's next-trip chip now opens that trip.
- On a trip under way or finished, the Overview's Documents card sat above the days; it is now last, under Notes.
- A desktop list drew a focus ring over the selection on click and on arrow keys.
- The Navigation Layout page squeezed its list so dragging was nearly impossible on a small phone.
- Certifications with no custom title appeared blank in the Documents "File under" picker, on course pages and on the Milestones card.
- Switching Equipment and Sets, or Certifications and Courses, felt slow or slid the whole window.

## ⚠️ Upgrade notes

- **The database upgrades from schema 290 to 318.** The migration runs once on first launch and the app takes an automatic backup beforehand, so there is nothing you need to do first. Along the way it clears the duplicate certification card photos already copied into Documents, turns each distinct checklist category into a section, gives every dive computer and transmitter its own Equipment item (aligning names, merging notes and adding transmitter items to past dives), sets tank VIP and hydro clocks from the entered inspection dates, and moves CNS, OTU and deco model values from stored tissue data into each dive's empty fields.
- **Update every device in your sync library.** This release raises the sync compatibility floor from 280 to 308, so a device still on v1.8.2 or earlier stops receiving changes from an updated device until it updates too. Its own changes still arrive on the updated device, so nothing is lost, but the older device falls behind until you update it.
- **Settings moved:** Decompression is under Settings > Safety > Decompression, and the old Safety page is Settings > Safety > Safety review; Connected accounts is in Settings > Data, not Photos & Media; import controls and data tools are under Settings > Data > Advanced > Import options and Data tools; rarely used backup controls (Keep the last N, backup folder, Save a backup file, password protection) are under Backups > Advanced; "Always hide labels" sits inside each of the Phone and Desktop tabs; a document's Delete is in its overflow menu.
- **Renamed:** the sync page is "Sync between devices", the backup page "Backups" and the photos hub "Photos & videos"; Transfers is Uploads, and Disconnect is "Stop keeping copies on this device"; the S3 and WebDAV pages are one "My own server" form; "From GPS fix" is "GPS position at surfacing"; the Boat and Shore methods no longer say "entry".
- **Gone:** the separate dive computer page (its controls are on the Equipment item; renaming or deleting the item renames or deletes the device), the separate Certifications, Courses, Media and Documents nav entries (now Training and Media with tabs), the "Finish setting up this device" card and Photos guided checklist, and the first-run "Keep fresh" option. On a device upgrading with an existing diver, the new Set up card starts hidden.
- **Numbers that change:** rebreather dives leave SAC and RMV averages, trends and records; Time Patterns has no Evening bucket, so dives regroup; per-cylinder SAC appears on dives where it was blank; buoyancy and weighting change for steel tanks with no material; regulators logged only on tanks now count toward their dive totals; tank VIP and hydro due dates and reminders can change; surface intervals and Insights can change for dives with edited profiles.
- **Plans that change:** switch depths follow the plan's water and each cylinder's own MOD, so existing plans may switch at different depths; Setup fields start empty with your Settings default as a hint, and later changes to a default apply to every plan that never overrode that field; a plan that skips the deco ceiling can no longer be converted to a dive; repetitive dives show more deco in contingencies and bailout; CCR plans without their own setpoints now use yours from Settings.
- **Behaviour that changes:** downloads go to the computer's owner by default (turn it off under Settings > Data > Import options); zooming the inline seascape card needs Ctrl/Cmd + wheel or a pinch; the map style button changes the one app-wide map style; every device opens Connections once on Who dives where; CCR dives with no recorded setpoints show empty setpoint fields with a hint; a custom tank preset sharing a built-in's name (such as AL80) is now used for new dives; "Reset to Defaults" no longer deletes built-in species used by a photo tag or site; the Console, Deep, Minimalist and Tropical presets look visibly different and the O2 toxicity warning badge is amber.
- **Only new defaults:** the new Site Details card order and nav order apply to new divers; use Reset to Default to adopt them.
- **Tags:** existing tags are not switched on for media or documents; turn on "Use for media" or "Use for documents" in Manage Tags.
- **Only new imports benefit from the importer fixes** (Dive Log sensor pressures, DiveMate XML and UDDF, MySSI CSV, divelogs.de photos, Suunto buddies and journal details, UDDF restore). Re-import the file to pick them up. Positions from recorded GPS tracks are filled in on new imports only; use Match on the Tracks page for dives already in the log. Apple Watch dives shifted by v1.8.0 or earlier are corrected only when you run the Apple Watch import again over their dates. Dives wiped by an earlier empty re-parse, weather fetched for the wrong hour (re-run Fetch weather) and dive times shifted by the old upgrade step are not repaired automatically.
- **Git sync** writes only to a branch it created and refuses any other existing branch, including main. A public repository syncs only with encrypted sync on, and Submersion resets the branch history to one commit once enough old data piles up. Git cannot hold photo copies.
- **Cross-device backup retention** is off by default. With it on, each device applies its own Keep number, so the folder settles at the smallest among devices with the switch on. Backups under 24 hours old are never removed.
- **Older builds in a mixed library** read a site with several entry methods as "not set" (and saving it there loses the list), see a trip or site shared with chosen profiles as private, do not show account nicknames, may leave extra regulators on a tank, and treat auto-created transmitter entries as configured. A device still on v1.8.2 keeps removing a shared library's account entry on each launch until it updates.
- **Not yet confirmed on hardware:** finding a Bluetooth computer saved on another device, the Halcyon Symbios retry, the Apeks DSX and i330R pairing change, the Cressi bonding change, the Intel Mac renderer and Windows video playback. Please report how they behave.
- **Platform notes:** Submersion now appears in the iOS and Android Share sheet for any JSON file (one that is not a Suunto export shows "Unsupported file type"); it does not become the default JSON app. Linux still cannot play videos, and shared colour-corrected videos are not available there.
- **No new permissions and no minimum operating system change** on macOS, Windows, iOS, Android or Linux.
